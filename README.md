# 系统时间快速修改脚本

一个小工具，可以帮你的电脑迅速改变系统时区和时间。  
  
## 开发原因

作者最近尝试折腾Claude，为了躲避a/的搜查导致频繁修改时区，实在厌烦所以写了一个桌面小脚本快速修改系统时间。我猜GitHub上已经有类似的项目，但自己开发一个更好玩一点（  
  
## 使用方法

### 运行环境
- Windows 10 / 11。
- 使用系统自带的 Windows PowerShell 5.1，无需额外安装依赖。
### 下载并启动
- 在本仓库页面点击 **Code → Download ZIP**
-  解压下载的压缩包
- 保持 `启动.cmd` 和 `Set-SystemTimezone.ps1` 位于同一文件夹
- 双击 `启动.cmd` 打开程序
### 切换系统时区
- 双击 `启动.cmd`（此处即使不选择以管理员身份运行也无关紧要）
- 界面顶部可以选择中文或 English
- 在界面顶部的“时间格式”下拉框切换 24 小时制或 12 小时制，默认使用 24 小时制
- 在目标时区下拉框中选择所需时区
- 选择“使用目标时区的当前时间”
- 点击“应用”。
程序启动后会自动获取网络时间，并显示所选时区的真实当前时间。点击“应用”会切换系统时区并校正系统时钟，即使之前手动改错时间、关闭后重新打开，也可以恢复。取时在后台进行，优先使用 NTP，失败后尝试 HTTPS 备用来源。HTTPS 时间存在秒级误差。取时失败时会提示并自动重试，自定义时间模式仍可使用。

### 设置自定义日期和时间
- 右键 `启动.cmd`，选择“以管理员身份运行”（此处必须以管理员身份运行！！！）
-  选择目标时区。
- 选择“设置目标时区的自定义日期和时间”
- 修改日期和时间，输入值按目标时区的当地时间解释
- 点击“应用”
自定义时间框会持续走动；手动修改后，从修改后的时间继续计时。只有点击“应用”才会修改系统设置

### 注意事项
- 修改会影响整个系统，关闭程序不会自动恢复原来的时区或时间
- 两种模式都会修改系统时钟，需要以管理员身份运行，设备管理策略也可能限制修改
- 如果 Windows 启用了自动校时，手动设置的系统时间之后可能被自动校正
- 部分时区实行夏令时，UTC 偏移会随日期变化（sb夏令时，整套工具最大史山）
- 学校或公司的设备管理策略可能限制脚本运行或系统设置修改
